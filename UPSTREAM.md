# Upstream attribution

CircuitForge is based on [Digital Logic Sim](https://github.com/SebLague/Digital-Logic-Sim) by Sebastian Lague.

The imported source lives in `Digital-Logic-Sim-src/` and is licensed under the MIT License. Its original copyright notice and licence text are retained there and reproduced in this repository's root `LICENSE` file.

CircuitForge's challenge-period work will be kept separate and documented through Git history and the project documentation. Planned additions include a browser-safe Unity WebGL simulation driver, a typed circuit command/query layer, and a WebMCP bridge that exposes structured circuit tools to browser agents.
